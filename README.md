# MBA-DATA-SCIENCE
Este repositório contém materiais, exercícios e projetos desenvolvidos durante o curso de Data Science e Analytics, na USP.


## Conteúdo
Aulas e Notas: Notas de aula, slides e materiais de leitura.

Exercícios: Conjuntos de exercícios para praticar as habilidades aprendidas.

Projetos: Projetos práticos que aplicam os conceitos e técnicas discutidos no curso.

Datasets: Conjuntos de dados utilizados para exercícios e projetos.

Scripts e Notebooks: Códigos e notebooks Jupyter com exemplos e soluções.

## Estrutura do Repositório
W.I.P


## Tecnologias Utilizadas
Linguagens de Programação: Python, R

Bibliotecas e Frameworks: Pandas, NumPy, Scikit-learn, TensorFlow, Keras, Matplotlib, Seaborn

Ferramentas de Visualização: Tableau, Power BI

Ambientes de Desenvolvimento: Jupyter Notebook, Google Colab
